# NeonVerse Gaming Hub

A futuristic gaming hub featuring interactive mini-games, vibrant visuals, and a sleek user interface.

## 🎮 Games

- **Tic-Tac-Toe** — Challenge yourself or a friend.
- **Memory Challenge** — Test your memory and concentration.
- **Shape Hunter** — Put your observation skills to the test.
- **Think a Number** — Try to guess the hidden number.

## 🛠️ Tech Stack

- React
- TypeScript
- Vite

## 🚀 Getting Started

### Prerequisites

Make sure you have Node.js and npm installed.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/ashish-algo/neonverse-gaming-hub.git
   ```

2. Navigate to the project directory:

   ```bash
   cd neonverse-gaming-hub
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.

## 📦 Production Build

To create a production build, run:

```bash
npm run build
```
